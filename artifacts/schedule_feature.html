Sistem Jadwal Pelajaran Sekolah Islam

Implementasi fitur input penjadwalan mata pelajaran sesuai layout terlampir dengan desain antarmuka lengkap
Django Python Bootstrap 5 PostgreSQL HTML/CSS JavaScript

Ringkasan Fitur

Sistem ini memungkinkan pengelolaan jadwal pelajaran untuk setiap kelas dengan tampilan grid mingguan 6 hari (Senin-Sabtu) dan 10 slot waktu per hari. Fitur ini dapat diakses melalui menu "Jadwal Pelajaran" dengan layout sesuai screenshot terlampir.

Arsitektur Teknis

Model Data

// models.py - Tambahan untuk Schedule & ScheduleDetail class Schedule(models.Model): DAY_CHOICES = [('SENIN', 'Senin'), ('SELASA', 'Selasa'), ...] TIME_SLOT_CHOICES = [('1', 'Jam 1'), ('2', 'Jam 2'), ...] schedule_id = models.BigAutoField(primary_key=True) grade = models.ForeignKey('Grade', verbose_name='Kelas') school_year = models.ForeignKey('SchoolYear') semester = models.CharField(max_length=1) description = models.CharField(max_length=200) schedule_code = models.CharField(max_length=20, unique=True) class ScheduleDetail(models.Model): detail_id = models.BigAutoField(primary_key=True) schedule = models.ForeignKey(Schedule, related_name='details') day = models.CharField(max_length=10, choices=Schedule.DAY_CHOICES) time_slot = models.CharField(max_length=2, choices=Schedule.TIME_SLOT_CHOICES) grade_subject = models.ForeignKey('GradeSubject') teacher = models.ForeignKey('Teacher') class Meta: unique_together = ('schedule', 'day', 'time_slot')

Fitur Utama

📊
Grid Jadwal Mingguan
Tampilan tabel 6 kolom (Senin-Sabtu) dengan 10 baris slot waktu. Setiap sel dapat diklik untuk mengedit mata pelajaran dan guru.
🎯
Auto-generate Kode Jadwal
Sistem otomatis menghasilkan kode jadwal berdasarkan kombinasi kelas, semester, dan tahun ajaran.
👨‍🏫
Filter Guru & Mapel
Hanya menampilkan mata pelajaran yang terdaftar untuk kelas tertentu dan guru yang ditugaskan.
📈
Ringkasan Jam Mapel
Tabel bawah menunjukkan total jam terpakai vs jam dialokasikan untuk setiap mata pelajaran.
⚡
AJAX Operations
Semua operasi edit dilakukan via AJAX tanpa refresh halaman: simpan slot, kosongkan slot, update guru.
🔒
Role-based Access
Menggunakan sistem autentikasi Django dengan decorator @role_required untuk menu 'JADWAL-PELAJARAN'.

Cara Menggunakan

Instalasi & Konfigurasi

# 1. Run migrations untuk tabel baru python manage.py migrate # 2. Akses melalui URL http://localhost:8000/apps/kurikulum/jadwal-pelajaran/ # 3. Tambah permission JADWAL-PELAJARAN di Auth Auth.objects.create(user_id=..., menu_id='JADWAL-PELAJARAN', ...)

Uji Coba Fitur

1. Pastikan ada data Grade, Subject, Teacher, GradeSubject, TeacherSubject
2. Buka menu Jadwal Pelajaran
3. Buat jadwal baru untuk kelas tertentu
4. Isi beberapa slot dengan mata pelajaran
5. Uji clear slot & update guru secara bulk
6. Cek ringkasan jam mapel

Sistem ini telah terintegrasi penuh dengan arsitektur Sekolah Islam menggunakan pola Django ORM, authentication decorators, dan template inheritance yang konsisten.

Fitur ini siap digunakan setelah menjalankan migrations dan menambahkan permission di Auth model.
